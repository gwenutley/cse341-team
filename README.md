# cse341-team
This project is a collaborative nutrition tracking API built with Node.js, Express, and MongoDB. It allows users to create and manage profiles, track food intake, log daily meals, and set personalized nutrition goals. The backend includes authentication, secure route protection, and Swagger documentation for easy testing and API exploration.

The team built this project together as a full-stack backend application focused on health and wellness tracking. It combines user management, food data storage, goal tracking, and daily log functionality into a single REST API that can support a larger health or fitness application. Each team member contributed to different parts of the project, including API development, authentication flow, data modeling, testing, and documentation.

Contributor note
This project was developed collaboratively by the team, with individual contributions across authentication, route structure, access control, API documentation, and data handling. The work reflects a shared effort to build a functional and well-documented backend service.
